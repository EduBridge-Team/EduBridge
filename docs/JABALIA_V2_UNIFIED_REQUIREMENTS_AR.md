## 1. الغرض والنطاق والمصادر

تجمع هذه النسخة ثلاث مجموعات من المدخلات: (أ) تقرير الجمعية الأصلي المؤلف من ثلاث صفحات؛ (ب) خطة EduBridge Institutions — Jabalia الإصدار الأول؛ (ج) إجابات الجمعية التفصيلية عن الجداول والمعلمين والقبول والحضور والتقارير والمراحل، كما وُثّقت في المحادثة ووثيقة `docs/JABALIA_2026_REQUIREMENTS_AND_BACKLOG.md`. وتضيف مراجعة ساكنة لأدلة التنفيذ في Laravel وReact وFlutter على `main` بتاريخ إعداد الوثيقة.

**قاعدة الترجيح:** تُعتمد الإجابات التشغيلية الأحدث حين تخالف المقترحات القديمة. أمّا مسارات العمل غير المحددة في الإجابات فيبقى وصفها «مقترحًا يحتاج اعتمادًا»، ولا يتحول إلى قرار نهائي تلقائيًا. وجود مسار API أو اختبار أو شاشة لا يثبت القبول الإنتاجي.

**البنية التشغيلية المعتمدة:** قاعدة كود مشتركة، ونشر جباليا معزول وظيفيًا عبر `jabalia.edubridge.win`، مع API/Web/PostgreSQL وهوية وصول وتخزين وسائط منفصل. وهذا ينسخ افتراض الخادم الخلفي المركزي وقاعدة البيانات المشتركة الوارد في خطة V1. لا تُنسخ بيانات مستخدمي EduBridge الرئيسيين إلى جباليا.

- مدير المدرسة ونائبه هما إدارة المدرسة. ينبغي تحديد صلاحيات كل منهما بصورة مستقلة؛ لا تعني تسمية نائب المدير منحه صلاحيات المدير كاملة تلقائيًا.
- يتحقق النظام من تعارض المعلم والشعبة والغرفة، ومن النصاب الأسبوعي، ويعرض جدولي المعلم والشعبة. الحصص البديلة/الانتظار مشمولة في المقترح الأصلي؛ الأتمتة الكاملة للتوزيع تحتاج قرار اعتماد.

## 3. المعلمون والموظفون والعقود

الوثائق المطلوبة لملف المعلم: **الشهادة الجامعية، السيرة الذاتية، شهادات الخبرة، صورة الهوية، نسخة العقد، وإنجازات المعلم**. العقود هي **عقود مشاريع مؤقتة**، ويجب الاحتفاظ بنسخة من كل عقد. الجهات الإدارية ذات العلاقة هي إدارة المدرسة وإدارة المؤسسة. ينبغي تحديد تاريخ بداية/نهاية العقد والتجديد والإصدار والاحتفاظ والسحب والتصدير والصلاحيات في مصفوفة يعتمدها الطرفان.

يجب الاحتفاظ بسجل تعيينات المعلمين وانتقالاتهم وقرارات تغيير الشعب/المواد دون محو التاريخ السابق. ولا يَعتبر هذا المستند سجلات التكليف الدراسي بديلًا قانونيًا لسجلات عقود العمل.

## 4. طلبات الالتحاق والتسجيل والقبول

**وثائق القبول وفق الجمعية:** تقرير فحص سمع من عيادة سمعية متخصصة، شهادة ميلاد الطالب، التقارير الطبية الخاصة بالطالب، صورة شخصية، وصورة هوية الأب. يبدأ الإجراء بتقديم **طلب التحاق** ورفع الملفات، ثم مراجعة الطلب واعتماده بمشاركة **الإدارة المدرسية والمرشد المدرسي**.

**مسار العمل المقترح ويحتاج إقرار الجمعية:** تقديم الطلب ← التحقق من اكتمال المرفقات ← مراجعة المرشد والإدارة ← قبول/رفض مع سبب ← تثبيت تسجيل الطالب في السنة والصف والشعبة. يجب تسجيل الجهة المعتمدة وقرارها وتاريخه والنسخة المعتمدة من المعايير، ومنع اعتبار إنشاء سجل طالب عامًا بديلًا عن هذه البوابة المتخصصة.

تُخزّن تقارير السمع والمعلومات الطبية والهويات كوثائق خاصة، مع تنزيل عبر صلاحيات محددة وتسجيل عمليات الاطلاع، لا بروابط وسائط عامة. يشمل ملف الطالب درجة السمع وطريقة التواصل المعتمدة (الإشارة أو قراءة الشفاه) والسجل الأكاديمي والطبي ضمن أضيق صلاحية ضرورية.

## 5. الحضور والغياب والإشعارات

- نظام حضور **الطلاب** مستقل عن نظام حضور **المعلمين والموظفين**.
- تسجيل حضور الطلاب **يوميًا** بواسطة **مربي الفصل المعتمد**. يمكن أن تتضمن المنصة أيضًا تسجيلًا حسب الحصة لأغراض التقارير، بشرط عدم مضاعفة أيام الحضور أو إرسال التنبيه بسبب تكرار الحصص.
- إذا تجاوز غياب الطالب **ثلاثة أيام متتالية** يرسل النظام إشعارًا إلى ولي الأمر (عند اليوم الدراسي الرابع). يجب اعتماد احتساب العطل والإجازات المدرسية قبل إقفال المعيار.
- التقرير الأصلي يطلب تنبيهًا فوريًا عند الغياب/التأخر، لكن الإجابة التشغيلية حددت عتبة الغياب المتصل؛ **المقترح**: إبقاء تنبيه التأخر الفوري وإشعار الغياب بعد أربعة أيام دوام لجباليا، لحين اعتماد سياسة الإشعارات كتابة.
- تشمل السجلات الإجازات، التأخر، المغادرة المبكرة، التصحيح والتعديل والملاحظات ومسؤولية تسجيلها.

## 6. السجلات والتقارير المدرسية

**تقارير المعلمين:** تقارير أنشطتهم، الالتزام بالحضور والغياب، الالتزام بالمهام الوظيفية، السجل المهني والعقود.  
**تقارير الطلاب:** قصص النجاح، الخطط الفردية العلاجية، الحضور والغياب، التقدم الأكاديمي.  
**دورة حياة الطالب:** تقديم الطلب، القبول، التسجيل، النقل، الترفيع، التخرج؛ الحضور والتأخير والمغادرة والإجازات؛ العلامات والاختبارات والنتائج الفصلية والسنوية والشهادات؛ الفحوصات الطبية.  
**سجلات الموظفين:** التعيين المباشر، الدوام، الإجازات والأنشطة.  
**الإشراف والتخطيط:** زيارات المشرفين وملاحظاتهم وتقاريرهم وإجراءات التصحيح ومتابعة إغلاقها؛ الخطة السنوية وخطط الأنشطة والأنشطة المدرسية.

أفادت الجمعية بوجود **نماذج معتمدة للجداول والعقود والحضور**. لا تُعد مطبوعات النظام مطابقة لها قبل استلام عينات فعلية واعتماد الاختلافات. يشمل النطاق **المرحلتين الابتدائية والإعدادية**.

## 7. المحور التعليمي البصري وNoor for Teachers

وفق تقرير المشروع الأصلي وخطة V1، يُبنى مسار تدريجي: (1) إدخال محتوى مرخص أو معتمد ومصدره؛ (2) فهرسة الكتب والوحدات والدروس والصفحات؛ (3) تحليل الدرس واستخراج المفاهيم؛ (4) تبسيط اللغة دون تغيير المعنى العلمي؛ (5) إنشاء خطة درس بصرية قابلة لمراجعة المعلم؛ (6) إنشاء أسئلة وأنشطة وأوراق عمل تفاعلية وقابلة للطباعة؛ (7) ربط الكلمات بمكتبة إشارات فلسطينية موثقة وصور/فيديو مناسب؛ (8) اعتماد المخرجات قبل نشرها للطلاب أو أولياء الأمور.

تشمل الواجهة صورًا وبطاقات وأيقونات وتغذية راجعة بصرية بدل الاقتصار على الصوت. ويشمل جسر ولي الأمر ملخصًا مصورًا للدرس والأنشطة اليومية مع صلاحيات مرتبطة بالطفل.

**قيد حاسم:** الكتب الوزارية غير متوفرة لدى الجمعية حاليًا. لذلك يُعد توفير مصادر تعليمية مناسبة ومسموح باستخدامها شرطًا مسبقًا لتفعيل التحويل الآلي الفعلي؛ لا يصح ادعاء إتاحة الكتب أو مواءمة المنهج كاملًا. يجب التحقق من إشارات PSL على يد مختصين ومستخدمين صم وعدم اختلاق إشارة عند غياب المرجع. إن اختصار زمن التحضير بنسبة تزيد على 60% هو **مؤشر مستهدف للاختبار** وليس نتيجة متحققة.

2. حسم معادلة المعلم الواحد: على مستوى الصف أم الشعبة، وتعريف صلاحيات المدير والنائب والمرشد ومربي الفصل وإدارة المؤسسة. [الجمعية]
3. اعتماد أيام العطل وآلية الاستمرار في سلسلة الغياب، وإرسال التنبيه وقناة الاستلام. [الجمعية]
4. توسعة أنواع وثائق المعلمين إلى CV والهوية والخبرة والمؤهل والإنجازات والعقود، وإضافة دورة حياة عقد مؤقت وتواريخه وسجل تغييراته. [Laravel + React + Flutter حسب القناة المعتمدة]
5. فصل ملفات القبول الحساسة وإلزام تقارير السمع وشهادة الميلاد وباقي المرفقات المحددة، مع مراجعة المرشد وإدارة المدرسة ورفض/إعادة استكمال. [Laravel + Web/Flutter]
6. تدقيق الصلاحيات وسجل الوصول إلى الملفات الطبية والهويات، والتحقق من حفظ النسخ الاحتياطية لكل مساحة تخزين فعلية. [Backend + DevOps]

**معيار اكتمال الدفعة:** عمليات CRUD + رفض صلاحيات/ملفات غير مطابقة + اختبارات إعادة الرفع والتنزيل والتدقيق + موافقة الجمعية على التدفق والبيانات المحمية.

### الدفعة B — الجداول والحضور والتقارير التشغيلية (P1)

1. استكمال إدارة جداول جباليا في Flutter وفق API الفعلي؛ عرض إعدادات الحصص ونصاب المادة وتعارضات المعلم/الشعبة/الغرفة.
2. التحقق من قيد مربي الفصل اليومي، وعدم تكرار الحضور اليومي بسبب سجل الحصة، وحساب الغياب عبر الإجازات والعطل وفق قاعدة الجمعية.
3. تطوير الأنشطة الوظيفية، تقرير المواظبة، قصص النجاح، الخطة الفردية العلاجية، الفحوصات، السجلات التأديبية/التعليمية المطلوبة، الزيارات الإشرافية والإجراءات التصحيحية.
4. استيراد/إعادة إنشاء النماذج المعتمدة للجداول والحضور والعقود مع معاينة PDF والطباعة.
5. إكمال دورة الطالب: القبول ثم النقل والترفيع والتخرج والنتائج والشهادات مع سجلات تاريخية غير قابلة للفقد.

**معيار اكتمال الدفعة:** سيناريو محاكى مستخدم حقيقي لكل دور على API وReact وFlutter، وتقارير تطابق بيانات اختبار ثابتة دون بيانات طلبة حقيقيين.

### الدفعة C — التعليم البصري والتجربة الميدانية (P1/P2)

1. تحديد مصدر دروس قانوني/معتمد بدل افتراض وجود الكتب الوزارية، ثم مراجعة ترخيصه وفهرسة صفحاته ووحداته.
2. اختبار Noor for Teachers على دروس فعلية: تبسيط، خطة تعليمية، أنشطة وأوراق عمل قابلة للتحرير والطباعة، وموافقة المعلم قبل النشر.
3. ربط إشارات PSL الموثقة بالدرس ومراجعتها من مختص بلغة الإشارة ومستخدمين صم؛ عند عدم وجود إشارة، يعرض «غير متوفر».
4. إيصال الملخصات المصورة لأولياء الأمور ومراجعة إمكانية الوصول بالعربية والشاشات الصغيرة والإنترنت الضعيف.
5. إجراء Pilot محدود واعتماد نتائج الاختبار الميداني والأمن والنسخ الاحتياطي ووقت التحضير وملاحظات الجمعية.

**معيار اكتمال الدفعة:** تأكيد جودة حقيقية من معلمين ومختصين ومستخدمين صم، وتقرير قياس خط أساس وزمن التحضير الجديد، وتوقيع قبول الجمعية.

9. ما المعايير الرسمية للنتائج الفصلية/السنوية والنجاح والترفيع والتخرج؟
10. ما سياسة المراسلة مع أولياء الأمور، ومتى تُعتمد بالتشاور مع الإدارة؟
